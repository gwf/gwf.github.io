Thanks to the good people at the MIT Press, all of the figures from *CBofN* may be freely used for non-commercial purposes. Thus, if you are teaching a class, giving a lecture, or just want to have them to look at, feel free to download and use any of the figures.

If you would like to have all of the figures, pick a distribution that is appropriate for you. Unix users will probably want tarballs (`TGZ` format) and windows users should probably stick to the ZIP files. Distributions that contain GIF images, have figure versions in 24, 100, and 300 DPI.

- [cbn-figs-all.tgz](legacy/cbn-figs-all.tgz) - Gzip'ed tar file containing all figures in all formats and sizes. (35.19 MB)

- [cbn-figs-all.zip](legacy/cbn-figs-all.zip) - ZIP file containing all figures in all formats and sizes. (35.18 MB)

- [cbn-figs-eps.tgz](legacy/cbn-figs-eps.tgz) - Gzip'ed tar file containing all figures in encapsulated PostScript format. (14.48 MB)

- [cbn-figs-eps.zip](legacy/cbn-figs-eps.zip) - ZIP file containing all figures in encapsulated PostScript format. (14.39 MB)

- [cbn-figs-gif.tgz](legacy/cbn-figs-gif.tgz) - Gzip'ed tar file containing all figures in GIF format and all sizes. (15.09 MB)

- [cbn-figs-gif.zip](legacy/cbn-figs-gif.zip) - ZIP file containing all figures in GIF format and all sizes (15.12 MB)

- [cbn-figs-pdf.tgz](legacy/cbn-figs-pdf.tgz) - Gzip'ed tar file containing all figures in portable document format. (5.60 MB)

- [cbn-figs-pdf.zip](legacy/cbn-figs-pdf.zip) - ZIP file containing all figures in portable document format. (5.65 MB)

Make sure to "shift click" these bad boys. Because these are so large, I'd be delighted to have volunteers mirror this site. Any takers?
